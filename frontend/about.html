About PhishGuard AI Project

AI-Based Real-Time Phishing Website Detection Using Ensemble Learning

An advanced cybersecurity solution combining gradient boosted decision trees, natural language transformers, graph embeddings, and Explainable AI (SHAP XAI) for real-time threat mitigation.

Final Year Engineering Project

System Architecture & Pipeline Workflow

Multi-Stage Inspection

1. Input Web URL

Intercepts suspicious website link from Web Dashboard or Browser Background Extension.

2. Feature Extractor

Extracts 30+ lexical metrics, domain length, SSL certificates, WHOIS age, and DNS MX records.

3. Ensemble AI Engine

Runs LightGBM tabular booster, BERT NLP semantic tokenizer, and GNN graph structure embeddings.

4. SHAP XAI Diagnostics

Calculates feature importance attributions to explain WHY the website was flagged.

Key Novelties & System Modules

Real-Time Machine Learning Inference

Evaluates web links in under 50 milliseconds using optimized LightGBM gradient decision trees.

Explainable AI (SHAP XAI)

Eliminates black-box ML ambiguity by visualizing exact feature contribution scores for cybersecurity analysts.

SQLite Historical Database

Persists scan history logs, risk scores, domain metadata, and SHAP JSON structures for auditability.

Background Protection Extension

Manifest V3 browser background listener providing passive real-time link protection.

Project Information

  • Project Title: AI-Based Phishing Detection
  • Domain: Cybersecurity & Machine Learning
  • ML Models: LightGBM, BERT, GNN
  • Explainability: SHAP (SHapley Additive exPlanations)
  • Frontend Stack: HTML5, CSS3, Vanilla JS
  • Backend Framework: Python Flask REST API
